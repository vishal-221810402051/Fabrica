# Architecture Decision Records

Architecture Decision Records document material decisions that shape Fabricgamma's architecture, implementation boundaries, operational behavior, or engineering safety posture.

## Numbering

ADRs use a zero-padded sequence:

```text
ADR-0001-short-title.md
ADR-0002-short-title.md
```

Numbers are never reused.

## Lifecycle

- Proposed: under review and not yet binding.
- Accepted: approved as the current architecture baseline.
- Superseded: replaced by a later ADR.
- Deprecated: discouraged for new work but still relevant historically.
- Rejected: considered and explicitly not adopted.

Superseded ADRs must link to the superseding ADR. Superseding ADRs must describe migration or compatibility impact where relevant.
