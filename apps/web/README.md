# Fabricgamma Web

Minimal Phase 1 React/Vite foundation for the Fabricgamma web application.

This app only exposes a status interface and health-check wiring. It does not contain a node editor, project model, 2D layout, 3D viewer, authentication, or microfluidic domain functionality.

## Commands

- `corepack pnpm --filter @fabrica/web dev`
- `corepack pnpm --filter @fabrica/web test`
- `corepack pnpm --filter @fabrica/web build`
